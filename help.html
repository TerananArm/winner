แนวคิดของระบบ

EduSched AI จัดตารางสอนด้วยแนวทาง Agentic AI (Plan – Act – Check – Explain) โดยแปลงข้อมูลของสถานศึกษาเป็นข้อจำกัดเชิงตรรกะ (Constraints) แล้วแก้ปัญหาด้วย CSP + Heuristic Search (Most-Constrained-First + Mulberry32 Seed) จากนั้นตรวจสอบซ้ำแบบ Zero-Collision Audit และสรุปเหตุผลเป็นตัวชี้วัด KPI เพื่อให้ผู้ใช้ตรวจสอบย้อนกลับได้ทุกคาบ

ขั้นตอนใช้งาน (End-to-End)

  1. นำเข้าข้อมูลพื้นฐาน: ห้องเรียน / กลุ่มนักเรียน / นักเรียน / อาจารย์ / รายวิชา (รองรับ Excel–CSV พร้อมแม่แบบ และมีหน้าต่างพรีวิวก่อนบันทึกทุกหน้า)
  2. กำหนด ภาระงานสอน และ ข้อมูลการลงทะเบียน (วิชาที่แต่ละกลุ่มเรียน)
  3. ไปที่เมนู ตารางสอน → กด ตรวจความพร้อม เพื่อตรวจข้อมูลและข้อจำกัดก่อนคำนวณ
  4. กด จัดตารางอัตโนมัติ (AI) ระบบจะแสดงความคืบหน้า 4 ขั้น และยกเลิกได้ระหว่างประมวลผล
  5. ตรวจผลด้วย KPI, ปุ่ม รายละเอียดการตรวจสอบ (Audit) และข้อความแจ้งปัญหาที่เข้าใจง่าย
  6. ส่งออก: Excel (.xlsx) / CSV / ปฏิทิน (.ics) / ส่งออก PDF โดยตรง และ สั่งพิมพ์ A4 แนวนอน

ข้อจำกัดที่ระบบบังคับใช้จริง

  • ครูหนึ่งท่านสอนได้ครั้งละหนึ่งคาบ (ไม่ชนคาบ) และไม่เกิน max_hours ชั่วโมง/สัปดาห์
  • ห้องเรียนหนึ่งห้องรับได้ครั้งละหนึ่งกลุ่ม และต้องมี ความจุ ≥ จำนวนนักเรียน ของกลุ่ม (หรือผลรวมกลุ่มที่เรียนร่วม)
  • กลุ่มเรียนหนึ่งกลุ่มเรียนได้ครั้งละหนึ่งวิชา (ไม่ชนเวลา) และวิชาปฏิบัติต่อเนื่องถูกจัดเป็นบล็อกติดกัน
  • คาบกิจกรรมหน้าเสาธง/โฮมรูม (จันทร์ คาบ 1) และช่วงพักเที่ยง (12:00–13:00) ถูกกันไว้ตายตัว
  • เวลาไม่สะดวกสอนของครู ถูกอ่านจากข้อมูลอาจารย์และตัดช่วงเวลานั้นออกก่อนจัด
  • เงื่อนไขพิเศษของนักเรียน ถูกแปลงเป็นกฎระดับกลุ่มเรียน: กลุ่มเรียนคู่ขนาน/เรียนร่วม → จัดวิชาร่วมพร้อมกลุ่มคู่; ระบบทวิภาคี → เว้นวันศุกร์สำหรับการฝึกงาน; นศท. → ไม่จัดคาบพุธ 13:00–16:00

การทำซ้ำและความโปร่งใส

  • ช่อง Seed ควบคุมความสุ่ม: Seed เดิม + ข้อมูลเดิม = ผลลัพธ์เดิมเสมอ (ทำซ้ำได้ 100%)
  • Audit Hash คำนวณจากเนื้อหาตารางจริง (กลุ่มเรียน–วัน–คาบ–วิชา–ครู–ห้อง) จึงใช้ยืนยันว่าผลลัพธ์ไม่ถูกแก้ภายหลัง
  • Stress Test วัดเวลาประมวลผลจริงในเบราว์เซอร์ พร้อมนับกฎที่วางได้/ถูกปฏิเสธ และตรวจข้อขัดแย้งคงเหลือ

คำถามที่พบบ่อย

จัดตารางแล้วมีบางวิชาไม่ถูกจัด? ระบบจะแจ้งจำนวนบล็อกที่จัดไม่ได้ — เปิด ตรวจความพร้อม เพื่อดูสาเหตุ (ห้องไม่พอ / ครูเต็มชั่วโมง / เงื่อนไขเวลา) พร้อมคำแนะนำ

ต้องการตารางพิมพ์ที่สะอาด? กดปุ่ม พิมพ์ ในหน้าตารางสอน ระบบจะพิมพ์เฉพาะตาราง (ไม่มีหัว/ท้ายเอกสาร) บนกระดาษ A4 แนวนอน

ต้องการตารางทั้งโรงเรียน? ใช้ปุ่ม ตารางสรุปรวม ในเครื่องมือเพิ่มเติม หรือส่งออกปฏิทิน .ics ไปใช้กับ Google Calendar / Microsoft Outlook
